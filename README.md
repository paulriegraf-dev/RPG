# Pauls Mini-Adventure

Ein textbasiertes Pixel-Rollenspiel und Spielleiter-Werkzeug in der Welt **Pauluso-Tanien**. Es läuft komplett im Browser – nichts installieren.

**▶ Spielen:** https://paulriegraf-dev.github.io/RPG/

## Gemeinsam spielen (1 Spielleiter + 1–4 Spieler)

**Spielleiter**
1. Die Seite öffnen und im Startmenü **Gemeinsam spielen (Raum öffnen)** wählen. Oben rechts erscheint ein Kasten mit dem 5-stelligen Code.
2. **Link kopieren** und an die Mitspieler schicken (oder nur den Code nennen). Im Kasten siehst du, wer schon da ist.
3. **Neues Abenteuer**: In der Heldenauswahl wählt jeder Mitspieler seinen Helden selbst. Du ergänzt die Gruppe und klickst **Gruppe bereit**.
4. Im Spiel steht der Raum rechts im Spielleiter-Bereich unter **Gemeinsam spielen** (Helden umverteilen, Mitspieler entfernen, Raum schließen).
   Einen Raum kannst du auch erst mitten im Spiel dort öffnen.

**Spieler**
1. Den Link öffnen (oder die Seite öffnen → **Mitspielen (Raum-Code)**), Namen eingeben → **Beitreten**.
2. In der Heldenauswahl auf die Karte deines Helden klicken (nochmal klicken gibt ihn frei).
3. Unten in der Leiste steht, wer dran ist. Du klickst, wenn dein Held dran ist:
   im Kampf nach der Reihenfolge, beim Erkunden über **Ich bin dran** oder dein Bild in der Gruppe.
4. **Mein Held** zeigt Leben, Geist, Techniken und Gepäck. Das Feld unten schickt Nachrichten an alle.
   Freitext unter dem Log geht ans Spiel, wenn du dran bist – sonst als Nachricht an alle.
5. Würfeln: den Würfel anklicken (oder Leertaste).

**Gut zu wissen**
- Das Spiel läuft im Browser des Spielleiters. Sein Fenster muss offen bleiben. Spielstände speichert nur er.
- Lädt der Spielleiter die Seite neu, öffnet sich der Raum mit demselben Code wieder; die Spieler verbinden sich von selbst neu.
- Die Browser verbinden sich direkt miteinander (WebRTC). Zum Finden dient der kostenlose Nachrichtendienst ntfy.sh (je Mitspieler nur zwei kurze Nachrichten).
- Zum Ausprobieren an einem Rechner: die Seite zweimal öffnen und hinten `?lokal=1` anhängen.
- Am gemeinsamen Bildschirm geht es wie immer ohne Raum.

## Auf eine Webseite legen

Den ganzen Ordner (index.html, musik/, CREDITS.md) auf einen Webspace mit **https** legen – oder als GitHub-Repository mit eingeschaltetem GitHub Pages (Settings → Pages → Branch `main`, Ordner `/`).
